CHIWIWI

Design system v2, codename Temple. Two skies, one metal: Nyx is night indigo with gold leaf, Helios is sunlit marble with bronze. Every corner is square; every rule is a 1dp hairline; Greek voice appears only in titles, roman numerals and the meander.

I

Arrival

The empty chat is the only place the sky shows: in Nyx, square stars twinkle in four slow groups, the whole field drifts, gold sparkles mark the brightest, and a meteor crosses every fourteen seconds. In Helios, a breathing sun with turning rays. The Eclipse waxes from new moon to full as the model really loads.

Nyx
Helios
Proof of life: the ring fills with real load progress; the disc goes new moon, crescent, quarter, gibbous, full. Ready = full disc. Writing = halo pulse.
Calm by default: 6 native-driver loops for the whole sky, all stopped under reduced motion.
Empty input shows the mic (voice mode); typing turns it into Send.
II

Chat

Home, always mounted. Claude/ChatGPT grammar: plain answer text on the page, a square block for you, a flat composer. The top bar carries the proof of life: the Eclipse waxes while the model loads and its halo pulses while it writes.

Nyx
Helios
Four icons, no more: menu, new chat, attach, and one action key that is mic when empty, send when typed, stop while streaming.
Square user block with a 2dp gold/bronze edge, so "you" reads by shape, not only by tint.
Stats line after every reply, from llama.cpp timings: speed, tokens, first token, draft acceptance when Turbo is on.
Streaming cursor is a lozenge (a square on its point), pulsing.

Model Vault

The full library returns (34+ entries) with every tag and filter. Density stays calm because there is exactly one framed item (the recommendation), rows share one rhythm, and tags are quiet hairline labels until you touch them.

Settings

The hub keeps all nine areas. Roman numerals replace a wall of icons; each section opens with a Cinzel title over a thin meander. Every row shows its current value, so the hub doubles as a status page.
